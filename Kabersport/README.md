# КАБЕРСПОРТ — сайт поиска игровых тиммейтов

## Запуск в Visual Studio Code
1. Распакуйте архив `КАБЕРСПОРТ.zip`.
2. Откройте папку `КАБЕРСПОРТ` в Visual Studio Code.
3. Откройте `index.html` в браузере. Удобнее всего установить расширение **Live Server**.
4. Нажмите правой кнопкой мыши на `index.html` → **Open with Live Server**.

Для загрузки Bootstrap нужен интернет, потому что CSS и JavaScript Bootstrap подключены через CDN.

## Файлы
- `index.html` — структура страницы и содержимое.
- `styles.css` — оформление, Flexbox, Grid и адаптивность.
- `script.js` — фильтры, избранное, добавление анкет и сохранение в localStorage.

## Что работает
- поиск по игровому нику;
- фильтр по игре, уровню и статусу онлайн;
- добавление собственной анкеты;
- кнопка контакта;
- избранное;
- сохранение анкет и избранного в браузере.

## Важно
Это учебный фронтенд-прототип. Анкеты хранятся только в localStorage конкретного браузера и не синхронизируются между пользователями. Для настоящего общего сервиса потребуется сервер, база данных, регистрация и безопасная система обмена сообщениями.

## Связь с лабораторными работами
1. HTML/CSS и форматирование текста — заголовки, абзацы, выделение.
2. Списки, ссылки, изображения — навигация, списки преимуществ и ссылки.
3. Таблицы — сравнительная таблица.
4. Блочная верстка — секции, карточки, шапка и подвал.
5. Flexbox — навигация, карточки и панели.
6. CSS Grid — сетки игроков, статистики и шагов.
7. Одностраничный сайт — все разделы на одной странице.
8. Bootstrap — адаптивная сетка, кнопки, формы и модальное окно.
